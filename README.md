Для выполнения лабораторных, необходимо вести разработку с использованием github. Соответственно: делаете `fork` (кнопочка сверху), и у вас появляется личная копия репозитория, внутри которого вы и работаете. (Далее, как обычно, его клонируете и можете приступать к работе)

После создания форка обязательно настройте защиту ветки `master` по инструкции [.github/rulesets/README.md](.github/rulesets/README.md): изменения в `master` вносятся только через pull request, и смержить его можно лишь после успешного прохождения тестов затронутых библиотек и линтера.
